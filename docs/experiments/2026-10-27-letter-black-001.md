# Initial Letter grayscale comparison

Date: 2026-10-27.

Both variants produced printed sheets. Raster analysis identified automatic
scaling in the preparation pipeline.

## Conditions and method

The trial used one official-driver page and one experimental page on Letter
paper. Before submission, the queue was idle and SNMP showed clear error bits.

The fixture contained 6–12 pt text, inset borders at 3.175/5/10 mm, a 20 mm
square, thin lines, a grid, and a 100 mm scale. Preparation used the sandboxed
pipeline and verified the generated XML and PPD against the build manifest.

The raster reader confirmed one 612 × 792 pt page per variant. Graphics-body
inspection found one page eject and channel code 0 in each stream.

## Raster scaling result

The scale diagnostic measured the longest thresholded horizontal run in the
fixture's scale region using the raster header's DPI.

| Variant | Original raster | Actual-size raster |
|---|---:|---:|
| Official | 97.508 mm | 100.259 mm |
| Experimental | 97.261 mm | 100.189 mm |

Logs showed that `pdftopdf` fitted the full page to the printable area.
Preparation now sets `print-scaling=none`.

The updated diagnostic accepts scale-run lengths within 100 ± 0.5 mm.
It rejected both original rasters with exit code 7 and accepted both corrected
rasters with exit code 0. Run lengths include stroke extents and pixel
quantization.

Corrected artifacts: `build/comparison-letter-actual-size/` (local).
The [actual-size trial](2026-10-27-letter-black-002.md) evaluates the corrected
experimental stream on paper.
